# ReplayKeeper 宣传片

目标：32 秒，1920×1080，30 fps，H.264 MP4；中文旁白、原创合成电子配乐、黑绿动态设计。

| 时间 | 主画面 | 旁白 |
|---|---|---|
| 0–4 秒 | 抽象游戏准星与时间轴，精彩瞬间凝聚 | 精彩的一刻，不该错过。 |
| 4–8 秒 | 即时回放状态从开启变为关闭，时间轴中断 | 即时回放，却可能悄悄关闭。 |
| 8–13 秒 | 图标与品牌登场 | 让回放守护，替你留意。 |
| 13–20 秒 | 检测 → 确认关闭 → 尝试开启；状态由红转绿 | 后台检测，确认关闭后，尝试重新开启。 |
| 20–25 秒 | 登录自启动、常驻托盘；真实程序状态窗口 | 登录自启动，安静常驻托盘。 |
| 25–32 秒 | 品牌收尾、回放箭头与三项能力 | 你专心游戏，它守护回放。 |

## 视觉与声音
- 石墨黑背景，荧光绿作为主色，关闭状态用少量珊瑚红。
- 大字号中文与英文品牌，克制的网格、轨迹、光点、呼吸与平滑转场。
- 保留原有品牌图标，旁白使用中文神经语音；配乐和提示音本地合成。
- 自动恢复为动效流程示意，明确标注；不声称已经录到真实恢复过程。
- 结束页注明：守护即时回放开关；实际录制受 NVIDIA 功能与环境限制。
- 制作时不改程序配置、不停止后台守护、不切换 NVIDIA 回放；完成后按用户要求随项目上传 GitHub。

## 交付
- ReplayKeeper-promo.mp4：带旁白、配乐、字幕的完整宣传片。
- poster.jpg：宣传片封面。
- render.py：可重复渲染的动画、声音和编码脚本。
- narration/：旁白片段与原始配音文本。
